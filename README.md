### Option 2: Run via Local Lightweight Web Server
```bash

```
Then visit: `http://localhost:8080` in your browser.

### Option 3: Import into Native Notion Desktop (`/Applications/Notion.app`)
1. Open your **Notion.app** on Mac.
2. In Notion, click **"Import"** at the bottom of the left sidebar.
3. Select **"Markdown & CSV"**.
4. Choose the file: `/Users/alikhalidalikhalid/.gemini/antigravity/scratch/spidey-os/notion_template.md`.
5. Upload your cover art from `assets/cover.jpg` as the Notion page cover!

## 🕸️ Features Overview

1. **⚡ Daily HQ (Command Center)**:
   - Priority-ranked daily tasks (`P0 Critical`, `P1 High Leverage`, `P2 Standard`).
   - Notion-style task completion with audio feedback ("Web-Thwip" sound synthesized via Web Audio API).
   - Quick Add Task shortcut: `⌘K` or click `+ New Task`.

2. **🕌 Spiritual Sanctuary (Deen HQ)**:
   - **5 Daily Prayers**: Fajr, Dhuhr, Asr, Maghrib, Isha with Arabic names, Jama'ah in mosque status, and streak tracking.

   - **Qiyam al-Layl & Tahajjud**: Night prayer completion checkbox, raka'at count, and du'a intention notes.

   - 4-Stage Kanban Pipeline: *Scripting ➔ Recording ➔ Editing ➔ Published*.
   - Platform separation for TikTok and YouTube.
   - Opening Hook, duration, and tag tracking.

4. **🧠 Deep Work & Study Hub**:
   - Cyber-Pomodoro Focus Timer (25m Work / 5m Break / 15m Long Break).
   - Audio bell alerts and automatic study hour logging.
   - Subjects & Syllabus tracker with logged vs. target hours.

5. **🕸️ Projects Matrix (Spider-Hub)**:
   - Side-by-side multi-project tracker with Priority badges (P0, P1, P2).
   - Tech stack tags (`Python`, `PyTorch`, `FastAPI`, `Next.js`).
   - Interactive progress adjuster buttons (`+10%`, `-10%`).

6. **📊 Neural Analytics (Visualizations)**:
   - Real-time Daily Completion Score gauge.
   - 7-Day Activity Heatmap.
   - Life Balance Telemetry bar charts.

7. **💾 Auto-Save & Export**:
   - Everything is persisted in your browser's `localStorage` automatically.
   - Click **"Export to Notion"** anytime to download an updated markdown file of your current state.
